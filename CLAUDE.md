# CLAUDE.md — контекст проекта для Claude Code

## Что это
Браузерная уличная игра: реальная карта (Leaflet + векторная подложка OpenFreeMap через MapLibre GL, данные OSM), туман войны, который открывается по GPS, и генеративные квесты в духе GTA, привязанные к реальным местам (Overpass API). Город по умолчанию — Владивосток. Концепт описан в `CONCEPT.md`.

## Запуск и проверка
- `npm start` → http://localhost:3000. Сборки нет: чистые ES-модули, Leaflet лежит в `vendor/`.
- В консоли браузера доступен `window.game` (`map`, `fog`, `player`, `pois`, `quests`, `districts`, `settings`).
  - Телепорт: `game.player.teleport(game.pois.get("lm:eagle"))`
  - Открыть туман: `game.fog.reveal(game.player.pos, 500)`
- Для e2e-проверок подходит Playwright: геолокацию можно подменить через `context.setGeolocation`.

## Архитектура
- `js/main.js`: сборка и игровой цикл (`requestAnimationFrame`, `dt` в секундах).
- `js/fog.js`: `FogOfWar` хранит `Set` ключей ячеек `"row:col"` (сетка 20 м, см. `geo.js`), сохраняет в localStorage. Слой — canvas в pane `fogPane`: маска открытых ячеек, размытая и вырезанная через `destination-out`.
- `js/player.js`: режимы `sim` (WASD, клик, время ×8 через `timeScale`) и `gps` (`watchPosition`, фильтр точности 60 м).
- `js/poi.js`: `PoiService` берёт места из Overpass (радиус 1,5 км, кэш на неделю по тайлам 0,02°) и сводит теги OSM к категориям `food|bar|park|view|water|culture|landmark|shop|auto|misc`. `LANDMARKS` — встроенные точки с id `lm:*`; координаты приблизительные.
- `js/quests/schema.js`: **контракт квеста**. Любой генератор возвращает «сырой» JSON с id точек, `resolveQuest()` проверяет его и подставляет объекты. Новый тип шага добавляется так: `STEP_TYPES` + `resolveQuest` + `engine._nextStep/_updateStep/_drawObjective` + описание в промпте `ollama.js`.
- `js/quests/engine.js`: метки-выдачи (до 3 случайных + открытые сюжетные), одно активное задание, провал возвращает метку для повтора.
- Все таймеры и скорости NPC считаются в игровом времени: `dt * player.timeScale`.
- `js/route.js`: пешеходные маршруты OSRM (`routing.openstreetmap.de/routed-foot`, CORS открыт), `Path.at(d)` — точка на полилинии. NPC в `tail` стоит, пока маршрут не готов; при ошибке идёт по прямой (`path.fallback`).
- `js/districts.js`: `DISTRICTS` — центры микрорайонов (координаты по остановкам, ±300 м); район точки — ближайший центр не дальше 1,8 км. % открытия считается по «уличным» ячейкам: пешеходные дороги района из Overpass растеризуются в ячейки тумана и кэшируются в `streets:<id>` (компактная строка). Пороги `MILESTONES` 25/50/75/90 % дают награду через `quests.grant()`. Ошибка Overpass → повтор через 2 минуты.
- `js/radar.js`: радар (canvas, 350 м, открытые ячейки + метки из `quests.radarBlips()`) и стрелка у края экрана на `quests.guideTarget()`; стрелка обходит радар.
- `js/basemap.js`: подложка — MapLibre GL 5.24 внутри Leaflet (`vendor/maplibre/`, плагин `maplibre-gl-leaflet`), векторные тайлы OpenFreeMap без ключа. Стиль `map/style.json` собирается `python tools/build-map-style.py` из их стиля «dark»: своя палитра, подписи `name:ru`, без границ/стран/регионов. Все адреса OpenFreeMap переписаны на протокол `ofm://`: MapLibre качает тайлы из воркера, мимо service worker, поэтому кэширует обработчик протокола в главном потоке (кэш `vlfog-tiles`, лимит 4000; TileJSON — network-first, остальное — cache-first). MapLibre 6 не берём: у него нет UMD-сборки, а плагин ждёт глобальный `maplibregl`.
- `js/offline.js` + `sw.js`: PWA. Файлы игры — network-first (кэш `vlfog-shell-vN`, при изменении списка файлов поднять `VERSION`). Кнопка «Сохранить карту» кладёт в `vlfog-tiles` тайлы z10–14 в радиусе 1 км, TileJSON, спрайты и глифы (`offlineUrls()`). В GPS-режиме держим Wake Lock.

## Соглашения
- Весь пользовательский текст на русском. Реплики пишутся в формате `"Имя: текст"`, UI подсвечивает имя.
- Текст от модели вставлять только через `textContent` (или `esc()` в engine). Модель — недоверенный источник.
- localStorage: только через `storage.js` (префикс `vlfog:`, try/catch).
- Автор в РФ: в интерфейсе не должно быть украинской символики. Leaflet 1.9 по умолчанию ставит флаг в подпись карты — префикс переопределён в `main.js` (`attributionControl.setPrefix`). При смене библиотеки карты или обновлении Leaflet проверить подпись снова.

## Известные ограничения и что делать дальше
1. **OpenFreeMap — бесплатный сервис без гарантий.** Если он станет недоступен, те же тайлы (OpenMapTiles) можно раздавать самим (Protomaps/PMTiles); меняется только источник в `tools/build-map-style.py`.
2. **Координаты `LANDMARKS` приблизительные.** Уточнить по OSM (лучше подтягивать по OSM id).
3. **Стиль карты** пока — перекрашенный «dark». Можно довести до «GTA-стиля»: подсветка важных мест, свои иконки, толщина дорог по зуму.
4. **Районы — диаграмма Вороного по центрам, границы не рисуются.** Можно уточнить центры и показать границы на карте; за 90 % района стоит дать нового персонажа (см. CONCEPT.md).
5. **Сохранение только локальное.** Для синхронизации между устройствами подойдёт Supabase (таблицы `fog_cells`, `quest_log`).
6. **Линия-подсказка к цели прямая.** Можно вести её по `walkRoute()` (перестраивать, если игрок ушёл с маршрута >50 м, не чаще раза в 15 с).
7. **Защита от читов GPS** (не критично): ограничить скорость между фиксами.
8. **Генерация**: сохранять понравившиеся и непонравившиеся квесты (кнопка оценки после миссии) в JSONL. Это датасет для дообучения локальной модели.
